# tizen3-root-ytad (split up)

This repository has been split into two independent projects:

| Repo | What it is |
|---|---|
| [tizen3-root](https://github.com/HFedorovskyi/tizen3-root) | root injector for Samsung 2017 / Tizen 3.0 TVs: uid 0 shell, job runner, reboot-proof watchdog, boot hooks |
| [tizen3-ytad](https://github.com/HFedorovskyi/tizen3-ytad) | ad-free stock YouTube on top of it: DNS pinning and a TLS MITM that strips ads |

Install `tizen3-root` first, then `tizen3-ytad`. Both repos carry English and Russian documentation (`README.md` / `README.ru.md`).
